# SmartУстаз: помощник преподавателя колледжа

Одностраничный сайт для подготовки плана занятия, конспекта и презентации. Работает в браузере, без сервера.

## Запуск на GitHub Pages

1. Создайте публичный репозиторий на github.com.
2. Нажмите Add file → Upload files и загрузите `index.html` и `README.md`.
3. Откройте Settings → Pages. В Source выберите Deploy from a branch, ветку main и папку `/ (root)`, затем Save.
4. Через пару минут сайт откроется по ссылке вида `https://<логин>.github.io/<репозиторий>/`.

## Использование

1. Откройте блок «Ключ OpenRouter и модель».
2. Вставьте свой ключ OpenRouter и укажите модель с пометкой `:free`. Список моделей: openrouter.ai/models.
3. Сохраните. Ключ остаётся только в браузере этого устройства.

## Важно

- Не загружайте в репозиторий файлы с ключами и не вставляйте ключ в код.
- Бесплатные модели отвечают медленнее и хуже держат формат JSON. Если генерация не работает, попробуйте другую модель.
- Образцы преподавателя хранятся в браузере. Сохраняйте их файлом через кнопку «Скачать образцы».
- Все суммы, номера счетов и нормативные ссылки перед использованием проверяйте вручную.
