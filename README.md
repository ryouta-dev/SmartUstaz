# SmartУстаз — рабочее пространство преподавателя

Статическое браузерное приложение для подготовки плана занятия, конспекта, практических заданий и презентации. Русский и казахский интерфейс. Сервер приложения и сборка не требуются.

## Быстрый запуск

Распакуйте архив целиком. Для локального запуска из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Просмотр интерфейса возможен и через index.html, но для API, загрузки файлов и предсказуемого хранения данных рекомендуется HTTP-сервер или GitHub Pages.

### Обновление GitHub Pages

1. Сохраните резервную копию существующей версии.
2. Загрузите **всё содержимое** папки проекта в корень репозитория: `index.html`, `app.js`, `styles.css`, папку `vendor` и документацию. Одного index.html теперь недостаточно.
3. Settings → Pages → Deploy from a branch → main → / (root).
4. После публикации обновите страницу с очисткой кеша (Ctrl+Shift+R).

Изменения подготовлены по предоставленному ZIP. Они не отправлены в GitHub автоматически.

## Подключение Intern AI Discovery

Откройте **Настройки**:

- Провайдер: **Intern AI Discovery**.
- Base URL: `https://discovery-api.intern-ai.org.cn/v1`.
- API-ключ: ваш ключ. Ограничения вида `sk-or-...` отсутствуют.
- Идентификатор модели: **точное имя доступной вам модели из кабинета провайдера**. Не подставляйте произвольное имя: API должен его поддерживать.
- Нажмите **Сохранить настройки**, затем **Проверить подключение**.

Приложение отправляет POST на `<Base URL>/chat/completions`, передавая `Authorization: Bearer <ключ>`, `model`, `messages`, `stream: false`. Не добавляйте `/chat/completions` в Base URL. Проверка подключения отправляет короткий запрос модели и может расходовать лимит.

**Важно:** реальное подключение к Discovery в среде разработки не проверено: внешняя сеть недоступна и рабочий ключ не предоставлен. Совместимость реализована на уровне OpenAI Chat Completions. Имена моделей, ограничения учётной записи и разрешения CORS нужно проверить у провайдера. Нет обещания совместимости с любым API: нужен именно поддерживаемый интерфейс.

Для OpenRouter выберите соответствующий профиль. Для другого совместимого сервиса выберите «Другой совместимый API» и заполните URL, ключ и модель. Приложение принимает любой непустой формат ключа; это **не обходит авторизацию** на сервере провайдера.

### Если запрос не работает

- **401/403** — ключ, доступ к модели или учётной записи отклонены.
- **429** — превышен лимит запросов / квота.
- **HTTP 4xx/5xx** — проверьте адрес, идентификатор модели, баланс и состояние сервиса.
- **Ошибка сети/CORS** — проверьте интернет и разрешение запросов с домена сайта. CORS нельзя исправить только JavaScript-кодом на GitHub Pages: провайдер должен разрешить origin сайта. Альтернатива — отдельный доверенный backend, который в эту версию не входит.
- **120 секунд** — запрос прерывается по тайм-ауту; можно повторить или выбрать другую модель.
- **Ответ обрезан / неверный JSON / неполные материалы** — попробуйте модель с большим лимитом вывода и лучшим соблюдением JSON.

## Хранение и безопасность

- По умолчанию ключ находится в памяти страницы и sessionStorage (сессия вкладки). Некоторые браузеры восстанавливают sessionStorage после восстановления закрытой сессии; для гарантированного удаления используйте кнопку «Удалить ключ».
- Постоянное хранение включается только флажком «Запомнить ключ на этом устройстве». localStorage **не зашифрован**; не включайте его на общем устройстве.
- Старый ключ OpenRouter автоматически читается для совместимости. Отключите запоминание и сохраните настройки либо удалите ключ, если не хотите сохранять его постоянно.
- При смене API-адреса приложение запрашивает подтверждение: ключ и материалы будут отправлены новому получателю.
- Разрешён HTTPS; HTTP — только для localhost/127.0.0.1/IPv6 loopback. URL с паролем, query-параметрами и fragment отклоняются. Редиректы API запрещены.
- Образцы, последний результат и его правки, язык, тема оформления и журнал времени хранятся в браузере. Очистка данных сайта удалит их. Не используйте персональные данные студентов.
- Образцы можно переносить JSON-файлом. Импорт ограничен 5 МБ / 200 записей, структуры нормализуются. Текстовые образцы обрезаются до 30 000 знаков, в запрос анализа попадают первые 24 000.
- Подключаемые сторонние скрипты выполняются в контексте страницы. Для рабочего использования с чувствительными данными рекомендуется самостоятельный аудит зависимостей и локальное размещение всех библиотек либо серверная архитектура.

## Экспорт и офлайн-режим

- Просмотр и редактирование примера, локальное хранение и экспорт образцов JSON не требуют API.
- Генерация и анализ образца требуют интернет и действительный ключ.
- PowerPoint: библиотека PptxGenJS включена локально в `vendor` с MIT-лицензией. Проверено скачивание и целостность PPTX с шестью слайдами. Ручная проверка учебного содержания и размещения длинного текста всё равно необходима.
- Word-экспорт и чтение DOCX используют исходные зависимости `docx@7.8.2` и `mammoth@1.6.0` с jsDelivr. Для них нужен доступ к CDN. Полная проверка Word-файла и чтения DOCX в текущей среде не выполнена: сеть заблокирована. Отсутствие библиотеки показывает понятное сообщение и не останавливает приложение.
- PDF напрямую не импортируется; текст можно скопировать вручную. Библиотека образцов принимает DOCX, TXT, MD, CSV. PPTX как исходный образец не читается: скопируйте текст слайдов.

## Проверки

В `tests/smoke.cjs` — 21 регрессионный сценарий с **имитацией API**, без реальных ключей и расходов. Результат прогона: `tests/last-run.json`. Проверены генерация, отмена, ошибки 401/403, 429 и 500, сеть, усечение ответа, сохранение, импорт, переключение языка/темы, клавиатурная навигация, отсутствие горизонтального переполнения при ширинах 320/390/1440.

Для повторения тестов требуется Node.js и Playwright:

```bash
npm install
npx playwright install chromium
# В отдельном терминале:
python3 -m http.server 8765
# Затем:
npm test
```

При необходимости задайте путь к установленному Chromium через `CHROMIUM_PATH`. Браузерные проверки не заменяют тестирование с реальным API, Safari/iOS и вашим набором документов.

## Структура

- `index.html` — семантическая разметка и базовые стили компонентов.
- `styles.css` — новая дизайн-система и адаптивная компоновка.
- `app.js` — интерфейс, API, нормализация, хранение, генерация и экспорт.
- `vendor/` — локальная библиотека PowerPoint и лицензия.
- `tests/` — регрессионные тесты и журнал прогона.

Материалы ИИ — черновики. Перед занятием проверяйте расчёты, правовые ссылки, профессиональную терминологию и ответы к заданиям.
