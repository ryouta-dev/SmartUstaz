# SmartUstaz 3.0 — базовый аудит

Дата проверки: 2026-10-16

## Состояние исходной версии

- Рабочая папка содержит статическое приложение версии `2.1.0` и `plan.md`.
- Пользователь подтвердил, что выданная папка является базовой версией для работы. Удалённый проект: `https://github.com/ryouta-dev/SmartUstaz`.
- В выданной папке каталога `.git` нет: локальный commit и ветку определить нельзя. В рамках текущего этапа удалённый репозиторий не используется; изменения выполняются только в этой папке. Git-снимок для отката в рабочей копии недоступен.
- В `package.json` заявлены тесты `transport.cjs`, `generation.cjs` и `smoke.cjs`, но в папке `tests/` найдены только `smoke.cjs` и `last-run.json`.
- `npm test` завершился с кодом 1: отсутствует `tests/transport.cjs`. Отдельный `npm run test:smoke` завершился с кодом 1: пакет `playwright` не установлен. Браузерные тесты в этой проверке не выполнены.
- `tests/last-run.json` содержит исторический отчёт о 21 сценарии с имитированным API; он не подтверждает состояние данного снимка.

## Карта browser storage

| Ключ | Хранилище | Назначение / форма по коду |
| --- | --- | --- |
| `su_lang` | localStorage | Язык интерфейса: `ru` или `kk` |
| `su_theme` | localStorage | Выбранная тема оформления |
| `su_prof` | localStorage | ID выбранной специальности |
| `su_tpl_v1` | localStorage | Массив образцов: ID, имя, тип документа, профиль, дата добавления |
| `su_result_v2` | localStorage | Последний результат: план, конспект, слайды, время, правки, завершённые части, источник и ошибки |
| `su_result_previous` | localStorage | Предыдущий результат перед новой генерацией |
| `su_log_v1` | localStorage | Массив записей замера времени: дата, тема, ручное время и время генерации |
| `su_api_base` | localStorage | Base URL AI API |
| `or_model` | localStorage | ID AI-модели |
| `su_stream` | localStorage | Флаг потокового ответа |
| `or_key` | localStorage, только при включённом запоминании | Пользовательский ключ AI API; legacy-ключ также читается при старте |
| `su_api_key` | sessionStorage | Пользовательский ключ AI API на сессию вкладки |

Настройки формы занятия между перезагрузками по этим обращениям не сохраняются; значения специальности и примеры берутся из кода. Значения результатов нормализуются при чтении, но миграция ещё не формализована отдельными версиями схем.

## Границы этого аудита

- Схемы установлены статическим чтением текущего кода; фактические данные браузерного профиля пользователя недоступны и не читались.
- Реальные API, экспорт в браузере и межбраузерное поведение не проверялись.
- Перед облачной миграцией требуется восстановить Git-историю или явно зафиксировать, что этот каталог — исходный архив, а также обеспечить воспроизводимый тестовый набор и установить зависимости.
