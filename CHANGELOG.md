# Версия 2.1 — компактная и потоковая генерация

- Компактный комплект по умолчанию; отдельное расширение конспекта и слайдов с подтверждением замены.
- План → параллельно конспект и слайды. Результаты каждого раздела сохраняются независимо; ошибка одного не отменяет другой.
- Незавершённый комплект восстанавливается после перезагрузки; повторяются только недостающие разделы. Ручные правки готового плана сохраняются при повторе.
- Добавлен отдельный api-client.js: OpenAI SSE, обычный JSON, границы UTF-8, LF/CRLF, служебные события, отмена, проверка окончания потока и усечения.
- Текст рассуждений не показывается. В интерфейсе — читаемый потоковый предпросмотр, таймер, статусы разделов и предупреждение при долгом отсутствии данных.
- Удалён общий тайм-аут 120 секунд. Новый контроль: 5 минут без входящих данных, сброс при каждом фрагменте, защитный максимум 30 минут на запрос.
- Переключатель потока для API без streaming; нет автоматического повтора запроса, который мог бы повторно расходовать лимит.
- Добавлено предупреждение при закрытии страницы во время запроса и сообщение, если браузер не позволяет сохранить результат.
- Исправлено нежелательное изменение языка материалов при переключении языка интерфейса.
- 40 сценариев прошли: 21 исходный, 11 транспортных, 8 сквозных. Сквозные проверки подтверждают реальное пересечение запросов, промежуточную выдачу, частичное сохранение, повтор и безопасное расширение на локальном HTTP/SSE-сервере.
- Выполнена визуальная проверка нового прогресса, мобильного отображения, частичного и полного результатов.
- Реальная скорость внешнего API и совместимость параметров конкретной модели не проверены. Изменения не опубликованы в GitHub.

# Изменения версии из предоставленного ZIP

## Дизайн и навигация
- Вместо зелёного оформления — тёмно-синяя навигация, синий акцент, белые поверхности и почти чёрный текст.
- Переработаны типографика, расстояния, формы, карточки, кнопки и предпросмотр слайдов; сохранены светлая и тёмная темы.
- Боковая навигация на широком экране, нижняя панель на телефоне, отдельный раздел настроек.
- Действие генерации больше не перекрывает поля формы; мобильная прокрутка ограничена областью над панелью навигации.
- Добавлены связи вкладок с панелями, стрелки/Home/End, фокус, ссылка пропуска навигации и сообщения ошибок для скринридеров.

## API
- Убрана жёсткая привязка к OpenRouter; поддерживается OpenAI-совместимый Chat Completions endpoint.
- Настраиваются Base URL, ключ и идентификатор модели. Новый профиль по умолчанию — Discovery, старые настройки OpenRouter мигрируют без потери.
- Формат ключа и суффикс :free не ограничены. Модель нужно указать самостоятельно, а ключ должен приниматься провайдером.
- Добавлены проверка соединения, тайм-аут 120 секунд, отмена и отдельные сообщения для авторизации, квоты, HTTP, сети/CORS, усечения и неверного JSON.
- Применяются запрет редиректов, HTTPS и подтверждение смены получателя данных.
- Ключ по умолчанию не записывается в постоянное хранилище. Запоминание явно включается пользователем; есть показ/скрытие и удаление.

## Исправленные дефекты
- CSS display:grid больше не делает скрытые индикаторы прогресса видимыми: добавлено общее правило [hidden].
- Смена языка/состояния API не разблокирует кнопки в середине генерации. Параллельные генерация и анализ образца запрещены.
- При ошибке API сохраняется предыдущий результат. Последний результат и его правки восстанавливаются после перезагрузки.
- Исправлен выбор образцов: план не использует конспект и наоборот; явное «Без образца» не сбрасывается при перерисовке.
- Неполные ответы плана, конспекта и слайдов проверяются до публикации результата. Отключённые кейсы и ошибки удаляются из ответа, если модель проигнорировала настройку.
- Импортируемые профили нормализуются, null/повреждённые элементы не роняют отрисовку. Ограничены размер файла и число записей импорта.
- Исправлены повреждённые кириллические символы и вводящие в заблуждение упоминания конкретного ИИ-сервиса.
- Убрано ложное утверждение «проверен преподавателем» из Word-футера.
- Вставка в редактируемый результат производится простым текстом, без исходного HTML.
- Проверка чисел журнала отклоняет бесконечность и значения вне диапазона 1–1000.
- При недоступном постоянном хранилище настройки могут применяться в памяти страницы.
- Шрифты заменены системным стеком; приложение не зависит от Google Fonts.
- PowerPoint-библиотека размещена локально. Сохранение PPTX проверено в браузере и проверкой ZIP-контейнера.

## Проверки и ограничения
- 21 автоматический сценарий пройден; необработанных JavaScript-ошибок в прогоне нет.
- API в тестах имитирован; реальная генерация Discovery не проверена, её модель и CORS неизвестны.
- Визуально проверены создание, настройки, библиотека, план, конспект, слайды, ошибка, дополнительные параметры, мобильная и тёмная версии.
- DOCX-экспорт и чтение Word зависят от внешнего CDN, недоступного в среде проверки. Проверено сообщение при отсутствии модуля, не содержимое Word-экспорта.
- Не проводилось тестирование Safari/iOS и нагрузочное тестирование. Отсутствие всех возможных ошибок не гарантируется.
- Изменения находятся только в архиве, не в удалённом GitHub-репозитории.
